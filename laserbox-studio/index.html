十個步驟完成 1:1 雷射切割外殼板件

01. 選擇外殼形狀點選右上角「＋ 新模型」，可選矩形、正多邊形柱、正多面體或斜邊控制盒範本。
02. 輸入內部淨尺寸矩形使用底部內部寬度 X 與深度 Z；高度 Y 一律是量體最高頂點，板厚只往外增加。
03. 調整上蓋傾角展開「上蓋傾角」輸入 RX/RZ 角度，側板與上板斜邊會自動幾何補償並生成卡榫。
04. 四片側板內收/外張可選擇「四邊同步」快速建立金字塔台，或個別設定前、後、左、右板傾角。
05. 多選上方倒邊與倒角在「上方倒邊/倒角」任意勾選四邊或四角，自動新增獨立雷切斜面板。
06. 加入自由內部隔板支援左右、前後與水平隔層，開啟卡榫時會在相鄰外殼板自動切出對應定位槽。
07. 設定板厚與卡榫寬度支援 2.7 / 3.0 / 5.0mm 等常用板厚與 Kerf 切縫補償，自動鋪滿對稱卡榫齒。
08. 編輯 2D 開孔與文字雕刻點選任一面板後按「編輯 2D 切割與雕刻」，可加入圓孔、散熱孔與雷射雕刻文字。
09. 3D 爆炸分解與尺標核對拖曳右上角「💥 分解」滑桿檢視卡榫咬合，並切換尺標與面板代號。
10. 輸出 1:1 SVG 與 DXF點擊「輸出雷切板件」，自動依 600×400mm 等板材排版並下載 1:1 SVG 或 DXF。
